# Tabs

関連するコンテンツを並列のカテゴリに分けて切り替えるための、タブの並びを表示するコンポーネントです。タブに対応するコンテンツの出し分けは、使う側で行います。
同じ画面の中で表示内容を切り替えるためのもので、別のページへの遷移には LinkButton などを使ってください。

## 基本の使い方

```tsx
import { Tab, TabList, Tabs } from 'wip-ui'

<Tabs>
  <TabList>
    <Tab id="profile">プロフィール</Tab>
    <Tab id="security">セキュリティ</Tab>
  </TabList>
</Tabs>
```

## 構成要素

| 部品 | 役割 |
|---|---|
| Tabs | タブ全体。選択状態を管理する |
| TabList | Tab を横に並べるコンテナ |
| Tab | 各タブの項目 |

## 使う場面

- 関連するコンテンツをカテゴリ別に切り替えて表示し、表示領域が長くなりすぎるのを抑えたいとき
- タブのラベルを見るだけで、コンテンツ全体の概要を把握できるようにしたいとき

## 使い方

### 分類

- [should] タブの項目は互いに関係があり、並列な関係にあるものにする
- [avoid] 順序や手順のある内容（ステップ1、ステップ2 など）をタブで分けない

### 項目

- [should] 項目の数は、タブがコンテンツの幅に収まる範囲でできるだけ少なくする
- [should] 権限不足などで一時的に選べないタブは、isDisabled で選べない状態にする

### ラベル

- [should] ラベルは短く、そのタブの内容を推測できるものにする
- [should] ラベルと、タブに対応するコンテンツの見出しをそろえる
- [avoid] アイコンだけのラベルにしない
- [avoid] アイコンを使うタブと使わないタブを混在させない

## 実装

- 選択中のタブに対応するコンテンツの表示は、Tabs では行わない。Tabs の onSelectionChange で選ばれた Tab の id を受け取り、使う側でコンテンツを出し分ける
- [should] 初期表示のタブを変えるときは、Tabs の defaultSelectedKey に Tab の id を指定する
