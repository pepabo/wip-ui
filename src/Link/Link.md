# Link

文章の中や、項目の値として置くテキストのリンクです。素の `<a>` の代わりに使います。文字は周りと同じ色で、下線でリンクであることを示します。画面の主な行き先をボタンの見た目で示すときは LinkButton を、移動ではなくその場で操作をするときは Button を使います。

## 基本の使い方

```tsx
import { Link } from 'wip-ui'

<Link href="/help">ヘルプ</Link>
```

## 使う場面

- 文章の中で、関連するページへ案内するとき（例：「詳しくはヘルプをご覧ください」）
- ドメインやリポジトリ名など、項目の値そのものが行き先になるとき

## 使い方

### 見た目
- 下線は常に表示される。hover のときだけ下線を出す見た目にはできない
- 文字の大きさと太さは、置いた場所のものを引き継ぐ
- [avoid] リンクでない文字に下線を付けない。下線がリンクの目印にならなくなる

### 色
- [should] 通常は neutral を使う
- [should] 暗い背景の上に置くときは white を使う

### 外部のサイト
- [should] 外部のサイトへのリンクは external を指定し、新しいタブで開くことを示す
- [avoid] サービスの中のページへのリンクに external を指定しない。新しいタブで開く必要がない

### 数
- [avoid] 1 つの画面や段落にリンクを並べすぎない。下線が並ぶと、どれが大事な行き先か分かりにくくなる
- [should] 同じ行き先へのリンクが近くに複数あるときは、1 つにまとめる

## 文言

- [should] リンクの文字だけで行き先が分かる言葉にする（例：「料金プラン」）
- [avoid] 「こちら」「詳しくはこちら」のように、行き先が分からない言葉にしない

## アクセシビリティ

- [must] リンクの文字を空にしない。アイコンだけで示すときは LinkButton の iconOnly を使う
- external を指定すると、スクリーンリーダー向けに「（新しいタブで開く）」が読み上げられる
- 下線があるため、色だけでリンクを区別させない（WCAG 1.4.1）条件を満たす

## 実装

- [avoid] Link の中に Button や LinkButton を入れない。押せるものが入れ子になる
