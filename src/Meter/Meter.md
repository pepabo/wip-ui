# Meter

ディスクの使用量や、プランの上限までの残りなど、決まった範囲の中の今の量をバーと数値で示します。
素の HTML の `<meter>` や、自作の使用量のバーの代わりに使います。アップロードなど、作業の進み具合を示すものではありません。読み込み中であることだけを示す場合は Loader を使ってください。

## 基本の使い方

```tsx
import { Meter } from 'wip-ui'

<Meter label="ディスク使用量" value={3.2} maxValue={10} valueLabel="3.2 GB / 10 GB" />
```

## 使う場面

- ディスク、メモリ、転送量など、上限が決まっている資源の使用量を示すとき
- プランや予算の上限に対して、今どれだけ使っているかを示すとき

## 使い方

### 使わない場面

- [avoid] 上限が決まっていない値には使わない。数値だけを文字で示す
- [avoid] 時間とともに 0% から 100% へ進む、作業の進み具合には使わない（例：アップロード、デプロイ）。Meter は、今どれだけ使っているかという量を示すもの

### 値

- 名前と値の文字は、label があるときだけ、バーの上に自動で表示される。label がないときは、バーだけが表示される
- [must] 表の中など label を出さない場合は、同じ場所に値の文字を書く。バーだけで量を伝えない
- [should] 値は、% だけでなく、単位の付いた量で示す（例：「3.2 GB / 10 GB」）。CPU 使用率のように、割合そのものが意味を持つ値は % でよい
- [should] 上限を超えた場合も、実際の量を示す（例：「12 GB / 10 GB」）。バーは上限で止まる

### 色

- color の色は、バーとアイコンにだけ付く。ラベルや値の文字の色は、状態によらず変わらない
- [should] 上限に近づいて対応が必要になったら notice、上限に達したら negative にする。どの値で切り替えるかは、サービスで決める（例：80% 以上で notice、100% で negative）
- [must] notice・negative にしたときは、description で今の状態と、次にすることを書く（例：「残りが少なくなっています。不要なファイルを削除してください」）
- [avoid] 状態を伝える必要がないときに、notice・negative を使わない

### 太さ

- [should] 数値の文字が主役で、バーを補助として並べる場合（表の中、設定の行、数値を大きく出すカード）は s にする

## 文言

- [should] ラベルは、何の量かが分かる名詞にする（例：「ディスク使用量」「今月の転送量」）
- [should] 値が更新される時期が決まっている場合は、description に書く（例：「1日1回、午前3時に更新されます」）

## アクセシビリティ

- [must] label か aria-label で、何の量かを伝える
- [must] 表の中など同じメーターが並ぶ場合は、aria-label に、どの行のものかを含める（例：「my-key の予算の使用状況」）
- [must] label を出さない場合も、valueLabel で、画面に書いた値の文字と同じ内容を渡す。渡さないと、読み上げでは % だけが伝わる
- [must] label を出さずに notice・negative にする場合は、同じ場所に状態を文字で書く（例：Sticker で「上限」）。バーの色だけで状態を伝えない
- アイコンは、label があり color が notice・negative のとき、値の文字の前に自動で表示される。アイコンは読み上げられないため、状態は description の文で伝える
