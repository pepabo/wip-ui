# Button

ユーザーのアクションを受け付けるためのボタンコンポーネントです。
素の `<button>` の代わりに使います。ページ遷移には LinkButton を使ってください。

## 基本の使い方

```tsx
import { Button } from 'wip-ui'

<Button onPress={handleSave}>保存</Button>
```

## 使う場面

- 保存・登録・送信・削除など、データに変更を加える処理を実行する
- 内容の確定や同意など、ユーザーの意思表示を受け付ける
- キャンセル・中止・解除など、操作を取り消す
- ダイアログを開くなど、データを変えずに UI の表示状態を切り替える

## 使い方

### 色・外観
- [should] 画面の目的を進める主要なアクション（保存、送信など）のボタンは、画面またはダイアログごとに1つにする
- [should] テーブルの行やカードなど、繰り返し出る要素の中のボタンは、主要なボタンより目立たない外観にする
- [should] 主要なアクションと副次のアクションは、外観で区別できるようにする
- 外観の目立つ順番は、フレーバーによらず flat ＞ outlined ＞ transparent
- 主要・副次のボタンにどの appearance と color を使うかは、フレーバーごとに異なる
- [should] エラーや削除など、注意が必要な破壊的なアクションには color="negative" を使う
- [avoid] カードなど、それ自体に輪郭がある要素の上では appearance="outlined" を使わない

### サイズ・幅
- [should] テーブル行内など、スペースが限られる場面では size="s" を使う
- [should] 申し込み・購入やオンボーディングの開始など、その画面で最も促したい行動のボタンには size="l" を使う
- [avoid] 広い画面のフォームで、送信ボタンを幅いっぱいにしない
- [avoid] size="s" のボタンに width="full" を使わない
- [should] 同列に並ぶボタンで、ラベルの文字量の差によって意図しない優先度の差が生まれる場合は幅を揃える

### 配置
- [should] 近くに並べるボタンは、同じ対象を操作するものだけにする
- [should] ダイアログなどでボタンを複数置く場合は横並びにし、主要な（処理を続行する）ボタンを右に置く

### フォーム
- [should] フォームは、送信ボタンを押したときも、入力欄で Enter キーを押したときも送信できるようにする

### 状態
- [should] 条件を満たしていない、または処理中で操作できない場合は isDisabled を使う

### アイコン
- [should] アクションの意味をアイコンで補強する場合は leading にアイコンを置く
- [should] 方向性や遷移先を示す場合は trailing にアイコンを置く
- [should] iconOnly は、保存・削除など一般的なアイコンで意味が伝わるアクションに限り、スペースが限られる場面で使う
- [avoid] 装飾目的でアイコンを付けない
- [avoid] 同じような機能のボタンが並ぶ場合はアイコンを付けない
- [avoid] キャンセルなど取り消し系のアクションにはアイコンを付けない
- [avoid] 「販売開始」のように一般的なシンボルがないアクションにはアイコンを付けない

## 文言

- [should] ラベルはボタンを押して実行されるアクションを表す
- [should] 「〜する」は省き、行為を表す名詞にする（「確認する」ではなく「確認」、「ログインする」ではなく「ログイン」）
- [should] 取り消し系のアクションには「キャンセル」「中止」「解除」など一般的な語を使う
- [should] 押してもすぐに効果が反映されず、追加の入力や手続きが必要な場合はラベル末尾に「…」を付ける。ただし申し込み・購入など、その画面で最も促したい行動のボタンには付けない
- [avoid] 「押す」「選択する」など、UI 操作そのものに言及するラベルにしない。ただし、閉じる以外の処理をしないボタンは「閉じる」でよい
- [avoid] 「無料新規登録」のように、インセンティブやベネフィットをラベルに含めない。それらはボタンの外側で示す
- [avoid] ラベルを2行にしない

## アクセシビリティ

- [must] iconOnly のときは aria-label などでボタンの名前を付ける

## 実装

- [should] フォームの送信ボタンは type="submit" にし、送信の処理は form の onSubmit に書く
