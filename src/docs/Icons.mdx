# Icons

wip-ui のアイコンは [inhouse のアイコントークン](https://design.pepabo.com/inhouse/flavors/icon/) に基づいた Material Design ベースのアイコンセットです。

## 使い方

```tsx
import { Icon } from 'wip-ui'

<Icon name="home" />
<Icon name="heart" size="l" />
<Icon name="star" size="s" color="#FFD700" />
```
