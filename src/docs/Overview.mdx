# wip-ui

wip-ui は、GMO ペパボの共通基盤デザインシステム [inhouse](https://design.pepabo.com/inhouse/) をベースにした React コンポーネントライブラリです。

## inhouse とは

inhouse は、ペパボが展開する複数サービスに共通するデザイン原則・ガイドライン・アセットを統一した共通基盤デザインシステムです。プロダクトデザインとコミュニケーションデザインの両方をカバーし、サービスごとのブランドを維持しながら一貫性を担保します。

詳細は [design.pepabo.com/inhouse](https://design.pepabo.com/inhouse/) を参照してください。

## フレーバー

inhouse の中核となる仕組みが **フレーバー（Flavor）** です。フレーバーは、ブランドごとに上書き可能なデザイントークンの集合で、以下の 5 つのカテゴリで構成されます。

- **Pepper**（デフォルト）
- **Minne**
- **Apollo**
- **Nachiguro**
- **Flippers**
- **Kung-pu**
- **Lolipop**

セットアップ方法は [Getting Started](?path=/docs/introduction-getting-started--docs) を参照してください。

## トークンの 2 層構造

デザイントークンはプリミティブトークンとセマンティックトークンの 2 層で管理されます。

- **プリミティブトークン**: 具体的な値を直接定義（例: `$blue-600: #3e6f99`）
- **セマンティックトークン**: 意味を持つ名前でプリミティブトークンを参照（例: `$informative-color: $blue-600`）

コンポーネントではセマンティックトークンを使用してください。フレーバーを切り替えた際に、プリミティブトークンの値が変わってもセマンティックな意味が保たれます。
