# Spacing

wip-ui のスペーシングは [inhouse のサイジングトークン](https://design.pepabo.com/inhouse/flavors/sizing/) に基づいています。16px と 24px を基準値として、タイポグラフィから導出されたスケールで統一されています。

## レイアウトコンポーネントの使い分け

### Stack — 1 次元の配列

子要素を縦または横に並べるシンプルなレイアウトに使います。

- ボタングループ、フォーム項目の縦並び、インライン要素の横並び
- `flexDirection` で方向、`gap` で間隔、`alignItems` / `justifyContent` で配置を制御

```tsx
<Stack flexDirection="row" gap="m" alignItems="center">
  <Button>キャンセル</Button>
  <Button color="interactive">保存</Button>
</Stack>
```

### Grid — 2 次元のグリッド

12 カラムグリッドによる複雑なレイアウトに使います。

- ページレイアウト（メイン + サイドバー）、カード一覧、ダッシュボード
- `GridItem` の `size` でカラム数を指定（合計 12）
- `offset` で開始位置をずらせる

```tsx
<Grid spacing="l">
  <GridItem size={8}>メインコンテンツ</GridItem>
  <GridItem size={4}>サイドバー</GridItem>
</Grid>
```

### Container — コンテンツ幅の制約

コンテンツの最大幅を制限するラッパーです。Grid や Stack の外側で使います。

## レスポンシブ対応

Stack・Grid ともにレスポンシブ対応しています。オブジェクトを渡すことで、ブレークポイントごとに値を変更できます。

```tsx
{/* モバイルでは縦並び、デスクトップでは横並び */}
<Stack flexDirection={{ xxs: 'column', m: 'row' }} gap={{ xxs: 's', m: 'l' }}>
  ...
</Stack>

{/* モバイルでは1列、タブレットで2列、デスクトップで4列 */}
<Grid spacing="m">
  <GridItem size={{ xxs: 12, s: 6, m: 4, l: 3 }}>...</GridItem>
</Grid>
```

ブレークポイントの定義は [Foundations/Breakpoints](?path=/docs/foundations-breakpoints--docs) を参照してください。
