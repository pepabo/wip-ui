# Breakpoints

wip-ui のレスポンシブ対応は 7 段階のブレークポイントで構成されています。

ブラウザのウィンドウ幅を変更すると、アクティブなブレークポイントがリアルタイムで切り替わります。

## レスポンシブ Props

多くのコンポーネントの prop がブレークポイントごとの指定に対応しています。単一の値を渡すと全画面幅で適用され、オブジェクトを渡すとブレークポイントごとに切り替わります。

```tsx
// 全画面幅で同じ値
<Stack gap="m">...</Stack>

// ブレークポイントごとに切り替え
<Stack gap={{ xxs: 's', m: 'l' }}>...</Stack>
```

## Responsive 型

レスポンシブ対応の prop は `Responsive<T>` 型で定義されています。

```typescript
type Responsive<T> = T | {
  xxs?: T
  xs?: T
  s?: T
  m?: T
  l?: T
  xl?: T
  xxl?: T
}
```

指定したブレークポイント以上の画面幅で値が適用されます。未指定のブレークポイントは、より小さいブレークポイントの値を継承します。
