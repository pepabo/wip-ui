# Sticker

商品やユーザーなどの対象に付け加える、「これは何か」を示す属性や分類の小さなラベルです。押して操作するものではなく、表示専用です。稼働中・失敗など、時間がたつと変わる状態は StatusIndicator、ページ内で読んでもらうべきメッセージや注意を伝えるときは Callout を使います。

## 基本の使い方

```tsx
import { Sticker } from 'wip-ui'

<Sticker color="informative">ベータ</Sticker>
```

## 使う場面

- 「既定」「現在のセッション」など、同じ種類の対象の中でどれかを示すとき
- 「おすすめ」「新機能」など、対象に補足や強調の情報を添えるとき
- タグやカテゴリなど、対象の分類を示すとき

## 使い方

### 色

- [should] タグ、カテゴリなど、意味の色を持たない分類には neutral を使う
- [should] 「ベータ」「新機能」「既定」など、補足の情報には informative を使う
- [should] 「公式」「無料」など、肯定的な属性には positive を使う
- [should] 「提供終了」「非対応」など、否定的な属性には negative を使う
- [should] 「提供終了予定」「非推奨」など、注意してほしい属性には notice を使う
- [should] 「おすすめ」「人気」など、ユーザーの注意を積極的に引きたいラベルには attention を使う

### サイズ

- [should] 隣に並ぶ文字の大きさに合わせる（例：本文の横は m、小さい文字の横や表のセルは s、見出しの横は l）

### 内容

- [should] 取りうるラベルの種類が決まっていて、同じ属性なら同じラベルになるものに使う
- [avoid] 「残り3日」「5件」のように、対象ごとに値が変わるものを入れない。文字列で表す
- [avoid] 対象の名前そのものを Sticker で表さない
- [avoid] 1つの対象に、属性を示す Sticker を複数付けない。タグやカテゴリは複数並べてよい
- [avoid] 時間・システム・ユーザーの操作で変わる状態を Sticker で示さない。StatusIndicator を使う

### 操作

- [avoid] 押して操作できるようにしない。リンクやボタンの代わりにしない

## アクセシビリティ

- [must] 属性や分類はラベルのテキストで伝える。色だけで意味を区別させない

## 実装

- Sticker は `<div>` として描画される
- [avoid] Typography（初期値では `<p>` を描画する）の中に置かない。`<p>` の中に `<div>` を置くことになり、HTML として不正になる
