# StatusIndicator

サイトやデプロイなどの対象の、今の状態（稼働中、ビルド中、失敗など）を、色の丸と文字で示します。面を持たないため、表や一覧に繰り返し並べても重くなりません。押して操作するものではなく、表示専用です。「おすすめ」「ベータ」など、「これは何か」を示す変わらない属性や分類は Sticker、すぐ対応してほしい状態を一目で気づかせるときは Callout を使います。

## 基本の使い方

```tsx
import { StatusIndicator } from 'wip-ui'

<StatusIndicator color="positive" label="稼働中" />
```

## 使う場面

- 「稼働中」「停止中」など、サイトやサーバーの今の状態を示すとき
- 「ビルド中」「成功」「失敗」など、処理の今の状態や結果を示すとき
- 「有効」「期限切れ」「アーカイブ」など、時間・システム・ユーザーの操作で変わる状態を示すとき

## 使い方

### 色

- 状態の色は、丸にだけ付く。文字の色は、状態によらず変わらない
- [should] 色は、状態の意味で選ぶ
  - positive：稼働中、成功など、正常に動いている・完了した状態
  - negative：失敗、エラー、期限切れなど、問題が起きている状態
  - notice：期限切れ間近、要確認など、このままだと問題になる状態
  - informative：ビルド中、デプロイ中など、処理が進んでいる状態
  - neutral：停止中、下書き、アーカイブなど、意図して止めている・まだ始まっていない状態

### 表の中

- [should] 1つの列には、1つの StatusIndicator だけを置く

### 処理中

- [should] ビルド中・起動中など、終わるのを待っている状態は isPending にする

### 丸だけの形

- [should] 丸だけにするのは、名前の横など、文字を置く場所がない場合に限る。表の状態の列では、文字ありの形にする

## 文言

- [should] 状態は、短い言葉にする（例：「稼働中」「失敗」）
- [should] 同じ状態には、画面が違っても同じ文言を使う

## アクセシビリティ

- [must] 丸だけのときは、aria-label で状態の文言を渡す（例：aria-label="稼働中"）
- [must] 丸だけのときは、色だけで状態を伝えない。同じ状態を、画面の別の場所に文字でも示す
- 状態が変わっても、読み上げで自動では知らされない

## 実装

- StatusIndicator は `<span>` として描画される。Typography や表のセルの中に置ける
- label を指定したときは、aria-label は使われない。読み上げには label の文言が使われる
