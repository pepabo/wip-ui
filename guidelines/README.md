# wip-ui ガイドライン

wip-ui を使って UI を実装・修正・レビューするときのガイドラインです。
AI エージェントも人も、このガイドラインを見て判断します。

## 進め方

1. **ルールを確認する** — rules.md
2. **使うコンポーネントを選ぶ** — selector.md
3. **コンポーネントの使い方を確認する** — 各コンポーネントの md（型定義と同じフォルダにある `<コンポーネント名>.md`）
   - 人が確認する場合は Storybook（https://pepabo.github.io/wip-ui/）

既存のコードをレビュー・置き換えするときも、同じ順で確認してください。

## 判断に迷ったら

使うべきコンポーネントが見つからない・判断できない場合は、独自実装せずに Slack の #hos-wip-ui に連絡してください。
