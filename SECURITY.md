# Security Policy

## Reporting a Vulnerability / 脆弱性の報告

**Do not file public issues, pull requests, or discussion posts for security-sensitive reports.**
**セキュリティ関連の問題は公開 issue / PR / Discussion で報告しないでください。**

Please report security issues privately via GitHub Security Advisories:
以下から非公開で報告してください:

👉 <https://github.com/pepabo/wip-ui/security/advisories/new>

We will acknowledge receipt and coordinate a disclosure timeline within a reasonable time frame.
受領後、合理的な期間内に応答し、開示スケジュールを調整します。

## Supported Versions

Only the latest minor release receives security updates.
最新のマイナーリリースのみセキュリティアップデートの対象です。
